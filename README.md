# Pihu Sethia — Basic React Portfolio

Built intentionally with **HTML5 + CSS3 + JavaScript + React basics**.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Edit your details
Open `src/main.jsx` and replace the placeholder email and social links with your real details.
